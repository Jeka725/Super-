# SUPER — ESP32-S3 ST7735S

A standalone animated boot/demo screen for an ESP32-S3 N16R8 with a 128x160 ST7735S TFT.

## Hardware

- ESP32-S3 N16R8
- ST7735S 1.8" 128x160
- SPI: SCK GPIO5, MOSI GPIO6
- CS GPIO16, DC GPIO7, RST GPIO15
- Backlight GPIO4

The display is rotated 180 degrees.

## Animation

The animation is generated in real time:
- animated star field
- neon energy rings
- moving beams
- pulsing energy core
- animated SUPER title

No SD card and no external video file are required.
